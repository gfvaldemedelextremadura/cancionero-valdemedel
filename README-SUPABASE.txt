CANCIONERO VALDEMEDEL v4.23 · USUARIOS CON CONTRASEÑA

1. Ejecuta supabase-setup.sql en SQL Editor.
2. En Supabase > Authentication > Providers > Email, deja activado Email.
3. Recomendado: desactiva Confirm email para que los miembros entren justo después de crear su contraseña.
4. El administrador autoriza cada correo desde la app.
5. Cada miembro pulsa “Primera vez: crear contraseña”, usa su correo autorizado y crea una contraseña de al menos 8 caracteres.
6. En accesos posteriores entra con correo y contraseña.
7. Sube todos los archivos a GitHub y espera a que Vercel indique Ready.
