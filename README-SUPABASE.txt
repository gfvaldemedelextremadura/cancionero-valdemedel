CANCIONERO VALDEMEDEL v4.12 · CONEXIÓN SUPABASE

1. En Supabase abre SQL Editor > New query.
2. Copia y ejecuta todo el archivo supabase-setup.sql.
3. El resultado final debe mostrar:
   tabla: performances
   rls_activo: true
   politicas: 4
4. Sube todos los archivos de esta carpeta a GitHub, sustituyendo los anteriores.
5. Espera a que Vercel indique Ready.
6. Cierra completamente la app y vuelve a abrirla.
7. Inicia sesión con gfvaldemedelextremadura@gmail.com.

La versión 4.12 ya no depende de jsDelivr ni de otra web externa para cargar
Supabase. Usa un conector incluido en la propia aplicación y actualiza las
actuaciones periódicamente.
